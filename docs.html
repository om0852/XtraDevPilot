Installation Guide

Set up Xtra DevPilot: the Chrome extension and the local MCP server.

1 Load Chrome Extension

Open chrome://extensions/, enable Developer mode, click Load unpacked, and select the extension/ directory.

2 Launch Local Server Bridge 

npx xtradevpilot-mcp

Listens on ws://127.0.0.1:42819. Extension connects automatically.

Xtra DevPilot AI Agent Skill

Xtra DevPilot is far more than reverse engineering. It empowers your AI agent (Antigravity, Cursor, Windsurf, Claude Desktop, Copilot) with 10 production-grade browser automation, debugging, testing, and scraping superpowers directly inside real Chrome.

bolt Instant 1-Click Skill Initializer (CLI)
Zero Config

Initialize the complete skill and IDE rules in any repository with a single terminal command:

Google Antigravity
npx xtradevpilot init-skill
Cursor AI (.mdc)
npx xtradevpilot init-skill --target cursor
Global User Config
npx xtradevpilot init-skill --global

devices Adding the Skill to Your Favorite IDE

Google Antigravity

Run npx xtradevpilot init-skill. The file is placed at .agents/skills/xtradevpilot/SKILL.md. AGY automatically activates it whenever browser tasks are detected.

Cursor AI

Run npx xtradevpilot init-skill --target cursor. Installs to .cursor/rules/xtradevpilot.mdc for automatic prompt inclusion during agent sessions.

Claude Desktop

Add the MCP configuration to claude_desktop_config.json and paste the skill rules into your Project Knowledge or Custom Instructions.

Windsurf & VS Code

Run npx xtradevpilot init-skill --target all to write rules to both .agents/ and .cursor/, usable by Roo Code, Cline, and Windsurf Cascade.

biotech Reverse Engineering 4-Step Sequence

Recommended Recipe 
# 1. Harvest client JS bundles, CSS & sourcemaps from active Chrome tab
npx xtradevpilot download-sources -o ./sources

# 2. Reconstruct original React/TypeScript source files from sourcemaps
npx xtradevpilot reconstruct ./sources -o ./src

# 3. Discover REST endpoints and generate OpenAPI 3.0 specification
npx xtradevpilot extract-endpoints ./sources -o openapi.json

# 4. Export complete authenticated forensic evidence bundle
npx xtradevpilot export-rea -o session-evidence.json
download-sources REA Core

Downloads client JS, CSS, sourcemaps, and assets from active tab with structured manifest.

npx xtradevpilot download-sources -o ./sources
reconstruct Code Recovery

Unpacks .map sourcemaps and recreates pristine original project directory tree.

npx xtradevpilot reconstruct ./sources -o ./src
extract-endpoints OpenAPI 3.0

Statically scans JS or HAR files and outputs an OpenAPI 3.0 REST spec.

npx xtradevpilot extract-endpoints ./sources -o openapi.json
export-rea Forensics

Exports live DOM, HAR waterfall, cookies, storage, and routes into canonical REA format.

npx xtradevpilot export-rea -o session-evidence.json
trace-action <sel> Correlator

Clicks or types into an element and isolates all triggered network requests.

npx xtradevpilot trace-action "#submit-btn" --action click
assert <sel> <cond> QA Engine

Deterministic assertions: is_visible, is_hidden, contains_text, has_value.

npx xtradevpilot assert "body" is_visible
dom [--clean] Context Saver

Extracts live outerHTML DOM. --clean strips SVGs and styles for 94% token savings.

npx xtradevpilot dom --clean --selector "main"
eval <javascript> Runtime JS

Evaluates JavaScript inside the page's MAIN execution context (Redux, Zustand, Pinia).

npx xtradevpilot eval "document.title"
init-skill [--target] AI Agent

Initializes full dual-mode AI agent SKILL.md and IDE rules for Antigravity, Cursor, and Windsurf.

npx xtradevpilot init-skill --target all

Option Description
--jsonEmit machine-readable JSON output for AI subagents and scripts.
--tab-id <id>Target a specific Chrome tab ID instead of active foreground tab.
-o, --output <path>Destination file or directory for saved outputs.
-s, --selector <sel>Scope DOM inspection, clicks, inputs, or tracing to CSS selector.
-c, --cleanStrip noisy SVG paths, script tags, and comments to save tokens.
-t, --timeout <ms>Custom timeout in milliseconds for element polling (default: 3000ms).
