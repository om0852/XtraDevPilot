6 Autonomous Reverse Engineering Tools

Give your AI agents direct surgical capabilities over any frontend application. Extract architectures, capture network payloads, reconstruct TypeScript models, and auto-generate OpenAPI specs.

01 / SCOPE layers

rea_scope_app

Holistic surface inspection of the active tab. Maps scripts, stylesheets, global namespaces, frameworks (React, Vue, Svelte, Angular), API roots, and state managers.

scope_app({ depth: 2 })
DOM Tree → State Graph → Agent Context
02 / SOURCEMAP code_blocks

rea_sourcemap_reconstruct

Discovers inline or linked .map files across bundles. Automatically reconstructs the original unminified TypeScript/JavaScript source tree locally.

reconstruct({ outputDir: "./src" })
Chunk Bundle → Source Tree Extraction
03 / TYPES schema

rea_reconstruct_types

Analyzes runtime objects, Redux/Zustand stores, network payloads, and GraphQL queries to infer exact TypeScript interfaces and Zod validation schemas.

infer_types({ format: "zod" })
Runtime Object → Strongly Typed Interface
04 / FLOW hub

rea_action_to_api

Correlates user UI interactions (button clicks, form inputs, route changes) with outgoing XHR/Fetch network calls to map business logic directly to endpoints.

trace_action({ selector: "#btn-pay" })
DOM Event → Trace → REST / RPC Route
05 / OPENAPI description

rea_generate_openapi

Synthesizes recorded network traffic, headers, query params, request bodies, and response schemas into a spec-compliant OpenAPI 3.1 YAML or JSON documentation.

generate_spec({ version: "3.1.0" })
Traffic Capture → Valid OpenAPI Spec
06 / SUITE folder_zip

rea_bundle

Runs the complete reverse-engineering pipeline in parallel. Bundles architecture reports, unminified source code, types, and API specs into a single developer ZIP.

bundle_all({ archive: true })
All Tools Executed → Standalone Artifact
